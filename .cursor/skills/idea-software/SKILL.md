# IdeaSoftware

如果我灵机一动需要写什么程序 就放到这里.

这里指本仓库根目录下的 `IdeaSoftware/`。

## 何时使用

用户要新写一个程序，且没有指定已有工程（`BallGame`、`Client`、`ExtraDoc`）时，用本 skill。

用户明确说了别的路径时，按用户指定的路径写，不用本 skill 改道。

## 放哪里

1. 路径：`IdeaSoftware/<程序名>/`。
2. 程序名用简短、见名知意的目录名（英文或拼音）。
3. 一个想法一个目录，不要把无关程序塞进同一个目录。
4. 不要放进 `BallGame`、`Client`、`ExtraDoc`，也不要改这些工程来承接这个新程序。

## 每个程序要自包含

目录里放可运行的代码，并写一份该程序自己的 `README.md`，只写三件事：

- 这程序做什么
- 怎么运行
- 依赖什么（没有就写无）
